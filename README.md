# ONG do Amor

Site institucional desenvolvido para uma ONG fictícia com o objetivo de apresentar seus projetos sociais, incentivar doações e possibilitar o cadastro de pessoas interessadas em participar das ações da organização.

## Sobre o projeto

O projeto foi desenvolvido como parte de uma atividade prática de Engenharia de Software, colocando em prática conhecimentos de desenvolvimento web, estruturação de páginas, estilização, interatividade, validação de formulários, consumo de API e versionamento.

A proposta do site é apresentar de forma simples e acessível as ações da ONG, como distribuição de alimentos e atividades educacionais.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* BrasilAPI
* Git
* GitHub

## Funcionalidades

* Página inicial com apresentação da ONG
* Página de projetos sociais
* Formulário de cadastro
* Validação dos campos obrigatórios
* Validação de CPF, telefone, CEP e e-mail
* Máscara automática para telefone
* Seleção de estado e carregamento das cidades através da BrasilAPI
* Armazenamento de informações utilizando `localStorage`
* Menu responsivo com versão para dispositivos móveis
* Layout responsivo
* Recursos de acessibilidade
* Mensagem de boas-vindas após o carregamento da página

## Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela, utilizando técnicas de CSS como:

* Flexbox
* CSS Grid
* Media Queries
* Unidades relativas
* Layout adaptável

Também foi implementado um menu hambúrguer para facilitar a navegação em dispositivos menores.

## Acessibilidade

Durante o desenvolvimento foram aplicadas algumas boas práticas de acessibilidade, incluindo:

* Textos alternativos nas imagens com `alt`
* Hierarquia adequada de títulos
* Uso de elementos semânticos do HTML5
* Campos de formulário identificados corretamente
* Navegação por teclado
* Destaque visual para elementos em foco

## Validação

O código HTML foi submetido ao validador W3C para verificar sua estrutura e conformidade com os padrões da web.

## Versionamento

O projeto foi versionado utilizando Git e disponibilizado no GitHub. As alterações foram registradas no repositório durante o desenvolvimento.

## Como executar

Não é necessário instalar nenhuma dependência para executar o projeto.

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Navegue pelas páginas utilizando o menu do site.

Este projeto teve como objetivo aplicar na prática conhecimentos de desenvolvimento web, organização de projetos, responsividade, acessibilidade, JavaScript, consumo de API e controle de versão.
